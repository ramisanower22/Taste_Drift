\# Taste Drift 🎬



Taste Drift is an ML-powered media preference analysis project that shows how a user's movie taste changes over time using Letterboxd and Netflix viewing history.



\## Features



\- Import Letterboxd or Netflix history

\- Generate movie embeddings using Sentence Transformers

\- Build taste vectors for different time periods

\- Measure taste drift using cosine similarity

\- Show Taste DNA with genre preferences

\- Detect Taste Eras using K-Means clustering

\- Visualize how preferences evolve over time

\- FastAPI backend + React frontend

\- MCP server for future AI-based taste analysis tools



\## Tech Stack



\- Python

\- FastAPI

\- React + TypeScript

\- Pandas / NumPy

\- Scikit-learn

\- Sentence Transformers

\- MCP

\- MovieLens dataset
